## 架构设计

### 三 Tab 结构（企业版微信）
```
/ im (App 壳加载)
├─ Tab 1 聊天    会话列表（置顶/免打扰/搜索）→ 聊天页
├─ Tab 2 通讯录  组织架构树（Department 树只读）→ 部门成员 → 点人发起单聊
└─ Tab 3 我的    头像/姓名/角色 · 退出登录 · 下载页入口
```
- 底部 Tab 栏：微信式（图标+文字，选中态绿色/主题色）；仅聊天 Tab 有未读总角标
- 路由：App 内状态切换（不刷新页面），shell 组件 `ImAppShell`

### 会话列表增强
- **置顶**：置顶会话排最前（灰底分隔）
- **免打扰**：免打扰会话未读显示灰点（非红点数字）
- **删除会话**：滑动手势或长按 → 删除（本地隐藏 hiddenAt，新消息自动复活，微信语义）
- **搜索**：顶部搜索栏（会话名/成员名过滤）
- **下拉刷新**：touch 下拉触发列表重取
- **数据方案（推荐服务端，换机不丢）**：ConversationMember 加 `isPinned Boolean`、`isMuted Boolean`、`hiddenAt DateTime?` 三列（微迁移，有先例）；REST `PATCH /api/conversations/:id/prefs {isPinned?, isMuted?, hiddenAt?}`

### 聊天页微信化细节
- **聊天背景**：微信灰 `#EDEDED`；气泡我方 `#95EC69`（已实现）
- **时间分隔线**：消息间隔 >5min 插入「昨天 14:23」式居中灰条
- **输入栏**：语音切换按钮（🔊/⌨️ 切换）——语音态按住说话
- **双击头像 @**：群聊内双击对方头像 → 输入框插入 @名字
- **长按菜单增强**：复制/引用/撤回/删除/多选/转发
- **消息多选**：多选模式（勾选圈）→ 底部操作条（转发/删除）
- **批量转发**：逐条转发到所选会话（合并转发二期）
- **消息删除**：仅自己设备不可见（本地 deletedIds 集合，localStorage）

### 语音消息（提前到 v1.2）
- 录音：MediaRecorder（webm/opus）按住说话 → 松开发送 / 上滑取消
- 上传：`POST /api/im/voice-upload`（multipart）→ `{FILE_ROOT}/im-voice/{uuid}.webm`，**不建 File 记录**（语音是聊天内容，不参与项目资料归档——与「附件必须关联项目」边界：仅文件/图片强制关联）
- 消息：MsgType 枚举加 `VOICE`（微迁移，双端 schema 同步）+ fileMeta `{voiceId, duration, size}`（不存服务端路径）
- 播放：气泡内播放按钮 + 时长；未播放语音时长红点（本地）
- im-server：Prisma 运行时校验枚举，已同步 schema（见数据变更表）；前端 socket 发送 type='VOICE' + fileMeta

### 群功能
- **@所有人**：发送时前端展开——将全部成员 userId（除自己）填入 mentions（im-server 加 3 行 mentions>20 守卫）；输入 @ 联想列表顶部加「所有人」项
- **群公告**：Conversation 加 `announcement String?` + `announcementAt DateTime?` 两列（微迁移）；`PATCH /api/conversations/:id/announcement`（仅 OWNER/ADMIN）；进群顶部横幅展示（可收起），新公告变更用 socket 广播现有机制（列表刷新）

### 通讯录（只读）
- 数据：`GET /api/org-chart` 或 departments（Department 树 + members，侦察确认现成）
- UI：左侧部门树/列表 → 点击展开成员（头像/姓名/部门/岗位）→ 点成员发起单聊（POST /conversations SINGLE 复用）

### 图片能力
- **相册多选**：一期 ≤9 张，循环上传逐条发送
- **图片浏览**：黑底全屏浏览（自实现：左右滑动/页码/保存按钮），不引第三方库
